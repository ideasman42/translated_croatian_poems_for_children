###################
If Trees Could Walk
###################

| If the trees walked,
| The forests would scatter in all directions.
| The trees would walk,
| And their branches would wave.
|
| If the trees walked,
| The parks too would stroll on Sundays with the strollers,
| And perhaps would even play a little with the players.
|
| If the trees walked,
| Among the birds there would be great confusion,
| For the nests too would set off on strolls.
|
| If the trees walked,
| I would write to an orange tree from the south,
| Let it come to my sick friend.
